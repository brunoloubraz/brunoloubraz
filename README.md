# 👋 Hi, I'm Bruno!

I'm a **Full Stack Software Developer** with over **2 years of professional experience** building applications and distributed systems in the financial sector.

I work primarily with **Clojure, ClojureScript, Apache Kafka, Apache Cassandra, and AWS**, developing backend services, REST APIs, frontend features, and cloud-based data pipelines. I'm also expanding my knowledge of **Java, Spring Boot, and DevOps** through personal projects.

## 💼 What I Do

- 🔧 Develop **backend services and REST APIs** with Clojure and **frontend features** with ClojureScript.
- 🔄 Integrate distributed services using **Apache Kafka** and event-driven architecture.
- ☁️ Work with data pipelines using **AWS Lambda, AWS Glue, Amazon S3, and Amazon Athena**.
- 📚 Pursuing an **MBA in Software Engineering at USP/ESALQ**.
